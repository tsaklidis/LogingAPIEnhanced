Public API endpoints

No authentication required. All responses are JSON.

Base URL: /api/v1
All public endpoints are read-only (GET) and do not require authentication. They expose data only from sensors in spaces marked as public.

List public sensors

GET /api/v1/public/sensors/
Returns all active sensors in public spaces.
[ { "id": "a1b2c3d4-...", "name": "DS18B20", "sensor_type": "DS18B20", "space_name": "Balcony", "home_name": "Home", "home_location": "Kozani" } ]

List sensor readings

GET /api/v1/public/sensors/{sensor_id}/readings/
Returns paginated readings for a public sensor, newest first.
Query parameters:
from_date — ISO 8601 datetime, filter readings after this time
to_date — ISO 8601 datetime, filter readings before this time
limit — page size (default 50, max 1000)
page — page number
GET /api/v1/public/sensors/{id}/readings/?from_date=2026-07-26T00:00:00Z&limit=100 { "count": 248, "next": "...?page=2", "previous": null, "results": [ { "id": 1234, "data": {"temperature": 25.6, "humidity": 48.2}, "recorded_at": "2026-07-26T12:30:00Z" } ] }

Latest sensor reading

GET /api/v1/public/sensors/{sensor_id}/readings/latest/
Returns the most recent reading for a public sensor. Served from cache for fast response.
{ "id": 1234, "data": {"temperature": 25.6, "humidity": 48.2}, "recorded_at": "2026-07-26T12:30:00Z" }

Health check

GET /api/v1/health/
Returns platform health status (database, cache).
{ "status": "healthy", "checks": {"database": "ok", "cache": "ok"} }
